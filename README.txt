VioShred — Two-String, Seven-Fret Violin
=========================================
A bowed-string synth instrument in the spirit of GeoShred, for Android.
Two strings, seven frets, multitouch, continuous glide, vibrato and reverb.

You have two files:
  * VioShred.apk   — a real Android app (recommended). Install once, opens from your app drawer.
  * violin.html    — the same instrument as a single web page. Runs in Chrome, no install.


--------------------------------------------------------------------------------
OPTION A — INSTALL THE APK ON YOUR SAMSUNG GALAXY A16
--------------------------------------------------------------------------------
1. Get VioShred.apk onto the phone. Easiest: email it to yourself and open the
   attachment on the phone, or copy it into the phone's "Download" folder via
   USB / Google Drive / any file-transfer app you already use.

2. On the phone open  Settings > Security and privacy > Auto Blocker
   and turn Auto Blocker OFF (or choose "Allow" when it asks).
   On One UI 6 / Android 14+, Auto Blocker silently blocks sideloaded apps —
   this is the single most common reason an APK "won't install".

3. Allow installing from the app you'll use to open the file:
   Settings > Apps > (three-dot menu) > Special access > Install unknown apps
   > select "My Files" (and Chrome, if you open it there) > Allow.

4. Open "My Files" > Downloads > tap VioShred.apk > Install > Open.
   If Play Protect warns, tap "Install anyway" — the app is signed and safe.

5. VioShred now appears in your app drawer like any other app.

NOTE: The APK is signed with a self-generated developer key. That is normal for
sideloaded apps and does not affect how it runs. It requests no permissions and
needs no internet connection — everything is local.


--------------------------------------------------------------------------------
OPTION B — RUN THE WEB PAGE (no install)
--------------------------------------------------------------------------------
1. Put violin.html on the phone (email it to yourself, or drop it in Downloads).

2. Open "My Files" > Downloads > tap violin.html > "Open with" > Chrome.
   (Or in Chrome type  file:///sdcard/Download/violin.html )

3. Tap "TAP TO PLAY" once — browsers require a tap before any sound can start.

4. To keep it handy: in Chrome tap the three-dot menu > "Add to Home screen".
   It then launches full-screen from your home screen like an app.

Any app that can display HTML works, including a browser inside other apps —
Chrome is simply the most reliable.


--------------------------------------------------------------------------------
HOW TO PLAY
--------------------------------------------------------------------------------
* Two glowing strings: gold = String 1, cyan = String 2.
* Touch a string and slide left/right to choose the note.
  - "open" area / the nut on the left = open string.
  - Fret numbers 1-7 raise the note by that many semitones.
* Slide vertically inside a string lane to change bow pressure (volume/attack).
* Play both strings at once — full multitouch.

Buttons along the top:
  Glide    ON  = continuous pitch as you slide (portamento, like a bowed slide).
           OFF = snaps cleanly to the nearest fret.
  Vibrato  ON  = gentle auto-vibrato, like a held bow on a violin.
  Reverb   ON  = concert-hall tail.
  Tuning       = pick the string pair. Default is the violin's low two
                 strings, G3 and D4. Also: Fifth D4-A4, Viola C3-G3,
                 Cello C2-G2, Low G2-D3.
  Volume       = master level.

The note names of both strings show in the top-right corner as you play.


--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------
No sound?              Tap "TAP TO PLAY" first — sound is locked until you do.
Volume very low?       Raise the phone media volume with the side buttons.
Still no sound?        Make sure the phone isn't in Silent/Do-Not-Disturb, and
                       that Chrome/app media isn't muted in the volume panel.
"App not installed"?   Auto Blocker is still on (step 2), or "Install unknown
                       apps" isn't allowed for the file manager (step 3).
Rotate the phone?      Works in both portrait and landscape; the board re-fits.
